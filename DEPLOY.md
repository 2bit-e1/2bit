# Публикация На Сервере

Автодеплоя нет: слияние pull request в `master` не обновляет сайт само по себе.
Корень сайта nginx: `/var/www/madboot/dist`. DNS, сертификаты и настройки nginx для этого обновления менять не нужно.

## 1. GitHub

Откройте pull request опубликованной ветки, проверьте, что целевая ветка - `master`, и нажмите **Merge pull request**, затем **Confirm merge**.
Если pull request уже имеет статус **Merged**, повторное слияние не требуется.

## 2. Терминал На Mac

Подключитесь к серверу:

```sh
ssh root@77.222.46.189
```

Пароль вводится только в терминале в ответ на запрос SSH. Символы пароля не отображаются.
Следующие команды выполняются уже на сервере, а не в локальной папке Mac.

## 3. Проверка И Резервная Копия

```sh
cd /var/www/madboot
git status --short
```

Если `git status --short` что-либо напечатал, остановитесь: на сервере есть локальные изменения или неотслеживаемые файлы, которые нужно сначала проверить.
Не используйте `git reset --hard`, `git clean` или принудительное переключение ветки.

Если вывода нет, выполните:

```sh
git branch "codex/server-before-motion-$(date +%Y%m%d-%H%M%S)"
cp -aL dist "/root/2bit-dist-backup-$(date +%Y%m%d-%H%M%S)"
git fetch origin
git switch master
git pull --ff-only origin master
```

Резервная ветка сохраняет прежний коммит даже при detached HEAD. Копия `dist` содержит фактически опубликованный сайт, который мог отличаться от текущего коммита.
Если любая команда завершилась ошибкой, не запускайте следующую.

## 4. Сборка И Проверка

```sh
npm run build
git log -1 --oneline
```

Зависимости этой версии не менялись. `npm ci` нужен только при отсутствии `node_modules` или явной ошибке зависимостей, а не при каждом обновлении.
Успешное завершение сборки подтверждает строка `built in ...` без ошибки и возврат командной строки.
Во время `npm run build` каталог `dist` пересобирается; старый открытый сайт может кратковременно запросить уже заменённый JS-файл. После завершения обновите страницу.

Проверьте в приватном окне:

- https://2bit.works/ - превью, контраст логотипа и запуск его анимации после 10 секунд бездействия.
- https://2bit.works/me - видео "Видео био" вместо фотографии.
- https://2bit.works/process - раскрытие медиа, подписи, прокрутка в обе стороны и закрытие.
- https://2bit.works/projects/mad-beer - переходы кадров, соседних проектов и возврат из "Инфо".
- https://2bit.works/projects/sasha-slepchuk - мобильная галерея без одновременной загрузки всех отложенных видео.

Ждать 5-10 минут после сборки не нужно. Перезапуск nginx тоже не нужен: он читает новые статические файлы из `dist`.

## Быстрый Откат Сборки

При необходимости вернуть опубликованные файлы сначала найдите созданную копию:

```sh
ls -dt /root/2bit-dist-backup-*
```

Далее замените `ИМЯ_КОПИИ` на точное имя нужного каталога из вывода:

```sh
mv /var/www/madboot/dist "/root/2bit-dist-failed-$(date +%Y%m%d-%H%M%S)"
cp -a /root/ИМЯ_КОПИИ /var/www/madboot/dist
```

Это возвращает файлы сайта и сохраняет неудачную сборку отдельно. Исходный код Git таким откатом не меняется; перед следующей публикацией нужно отдельно согласовать нужный коммит.
