# 2bit Project Contract

- Existing Vue 3 / Vite / Pinia / vue-router portfolio. Keep this stack and the manual nginx deployment workflow. Do not introduce React, Sites hosting, a UI framework, or a motion dependency.
- Content lives in `src/data`; routes are `/`, `/me`, `/process`, and `/projects/:slug`.
- Motion work must preserve typography, the project grid, all layout tracks, breakpoints (especially 768px and 1024px), media fitting, labels, captions, and navigation positions.
- Reference: https://www.iakovlev.co/. Adapt its masked text and long decelerating media movement; do not copy its layout or content.
- Work locally until the user explicitly approves publication. The user approved publishing this motion/bio/logo release on 2026-10-26; this does not authorize future releases automatically. Preserve the homepage except for the requested adaptive black/white preview labels and logo behavior.
- Centralize motion tokens in `src/styles/motion.css`. Reveal easing: `cubic-bezier(0.32, 0.01, 0, 1)`. Prefer transform and opacity; media may use an inset clip on its own frame. Never animate full-page filters or cover content with strips/gradient overlays.
- Text: mount/intersection -> masked 105% vertical offset and zero opacity -> resting position/opacity 1; 720ms transform, 400ms opacity; 35ms line stagger capped at 210ms. Resize/font changes must recalculate lines without replaying already visible text.
- Navigation text: state change -> 105% offset/opacity 0 -> resting position/opacity 1; enter 520ms, exit 180ms; stagger capped at 140ms. Use interruptible CSS transitions.
- Project counter: change only the current number inside a stable two-digit mask; old/new numbers slide together in the gallery direction using the text reveal easing, 520ms, with no per-slide stagger or opacity gap. Respect reduced motion. Opening Info must block gallery navigation; closing it must clear the navigation cooldown and immediately restore wheel input, including above the header/footer. Never remount/reload the gallery. Clear Locomotive's inline pointer-events on the closed Info layer and remove global input listeners/timers on gallery unmount.
- Project, process, and bio media: ready/intersecting -> collapsed inset frame with the subject offset 18% and scaled 115% -> fully open frame, resting subject at 100%; 1050ms clip, 1200ms transform with reveal easing. Downward scroll reveals bottom to top; upward scroll reveals top to bottom. Re-entering offscreen media replays in the current direction; never reset an item while it is still visible. Observe stable, unclipped bounds, including nested and Locomotive scroll containers. Keep outgoing desktop slides underneath the incoming frame. No opacity wash, cover layer, layout/fit changes, or media duplication. Scale only the subject inside its clipped frame, never the surrounding layout.
- Frame changes: the outgoing frame closes in the complementary direction with the same 1050ms clip timing, its subject moves 12% in the scroll direction and scales to 103.5%. Remove it after exit; do not interrupt the 1200ms entry with a shorter fixed cooldown. Process popup may retain only the outgoing and incoming items during this transition, never duplicate galleries. Animate the old caption out while the new caption enters.
- Project-to-project changes must use the same concurrent masked transition as Process, with no scene dissolve or artificial route wait. Keep the desktop viewer mounted; retain only the outgoing frame from the previous project, never its full gallery. Project name/year/roles/count roll together in keyed snapshot layers, in the scroll direction, without opacity fading or out-in sequencing. Browser back and forward must remain usable.
- Home preview: fine-pointer hover/focus -> ready media crossfade (240ms) and scale 1.035 -> 1 (900ms). Keep the previous ready preview while a requested asset loads. Hover must not navigate. Cancel pending leave when the next item is entered.
- Home preview labels and logo: only pure black or white, chosen independently from local background luminance under each label/logo. The logo uses `--preview-logo-invert`, not the active-project flag, with a filter limited to the logo itself. Never use colored difference blending or filters on the page/media. Sample the existing decoded preview through one small reusable canvas; images on change/load/resize, video at most twice per second while visible. Stop sampling and clear owned CSS variables on leave/unmount. Verify white, black, colored, and split backdrops.
- Home logo keeps its hover/touch/click animation and also replays after 10 seconds of inactivity. Configure with `HOME_LOGO_ANIMATION` in `src/utils/constants.js`. Use one timeout, reset the idle window on pointer/keyboard/wheel activity, do not interrupt an animation with an idle replay, and stop timing/playback off the home route, in hidden tabs, or with reduced motion. Remove owned listeners/timers on unmount.
- Gallery boundaries: down from the last frame opens the next project at its first frame; up from the first frame opens the previous project at its last frame. Stop at project 1/9, without wrapping or preloading whole adjacent galleries. Preserve mobile native scrolling; require a new outward gesture at the top/bottom and restore the appropriate end when entering a project. No forced three-second project loading delay.
